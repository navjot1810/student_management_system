# student_management_system
The Student Management System is a Python-based desktop application developed using Tkinter. It is designed to manage and organize student information in a simple and user-friendly way. The system allows users to add, update, delete, search, and view student records efficiently. 
The application stores important student details such as Roll Number, Name, Date of Birth, Contact Number, Email, Gender, Admission Number, State, City, PIN Code, and Address. It also provides a course management feature where users can add or remove courses and view the courses enrolled by each student.
The system reduces manual paperwork and makes student record management faster and more organized. It provides buttons such as Save, Update, Delete, Clear, and Search for performing different operations. A table is also provided to display student records in a structured format.

Technologies Used:
Python
Tkinter
ttk (Tkinter themed widgets)
